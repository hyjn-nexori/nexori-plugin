# Nexori

Nexori is a Hytale network plugin for operators who want to connect separate servers into one coordinated multiplayer experience.
It supports connected adventure worlds, queue-driven minigames, instanced match flow, return-to-lobby behavior, and in-game administration for the tenant.
This repository is the official technical and documentation hub for the Nexori project.

## What Nexori Is For

Nexori is built for operators who want one connected multiplayer experience without first building a separate backend platform.

With Nexori, one tenant can:

- connect separate servers into one trusted network
- run connected adventure or travel worlds
- launch players through queues into instanced minigames
- return players cleanly to the lobby after match resolution
- manage core setup and administration from an in-game UI and workflow
