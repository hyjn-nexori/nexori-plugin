# Nexori License FAQ

This FAQ is a practical summary of `LICENSE.md`. It does not replace the license text. If there is any inconsistency, `LICENSE.md` controls. Official Nexori repositories, releases, and channels are identified in `OFFICIAL_SOURCES.md`.


## Is Nexori open source?

No. Nexori is source-available, not open source.

## Can I read the source code?

Yes. Inspecting and reviewing the source code is allowed.

## Can I run Nexori on my own server?

Yes. You may run Nexori on your own server, server network, tenant, game, or community.


## Does running a public-facing game server or multiplayer network for players count as a prohibited Hosted Service or Managed Service?

No, not by itself.

Running your own player-facing server, server network, or multiplayer community with Nexori is allowed, including monetized operation for your own players.

What is prohibited is offering Nexori itself, or a materially Nexori-based dashboard, control layer, backend, admin layer, orchestration layer, analytics platform, or managed platform, to third parties as a product or service.

## Can I monetize my player base if I use Nexori?

Yes. Permitted Server Monetization is allowed. You may charge players for gameplay access, cosmetics, perks, ranks, starter packs, subscriptions, content, or similar player-facing monetization tied to your own operated server, game, or community.

What is not allowed is charging third parties for Nexori itself or for a Nexori-based hosted, managed, or competing platform.

## Can I modify Nexori privately for my own tenant or servers?

Yes. Private/internal modifications are allowed for your own operations.

## Can I keep a private internal fork?

Yes. Private/internal forks used only for your own operations are allowed.

## Can I use employees, contractors, cloud providers, hosting providers, CI/CD services, private artifact stores, or security review vendors to support my internal deployment?

Yes, if they act only on your behalf, are subject to confidentiality or materially equivalent restrictions, and do not receive independent rights to exploit Nexori.

## Can I publish my modified version?

No. Public redistribution of modified Nexori is not allowed.

## Can I publish a public fork on GitHub or elsewhere?

No. Public forks are not allowed.

## Can I distribute a modified jar, build, container image, or package?

No. Public redistribution of modified or repackaged Nexori artifacts is not allowed.

## Can I publish a public patch set or change bundle for my Nexori modifications?

No. If the patch set or bundle would materially allow others to recreate a modified version of Nexori, it is not allowed.

## Can I rebrand Nexori and distribute it under another name?

No. Rebranding and white-label distribution are not allowed.

## Can I create a SaaS, dashboard, analytics platform, control platform, managed service, or hosted layer on top of Nexori and sell it?

No. Offering Nexori, modified Nexori, or materially Nexori-based functionality as a hosted, managed, multi-tenant, or third-party-facing service is not allowed.

## Can I charge other server owners for access to a platform based on Nexori?

No. That would be commercialization of Nexori or a competing Nexori-based platform, which is not allowed.

## Can I build private internal tools around my own Nexori deployment?

Yes. Private internal dashboards, scripts, reporting tools, and operational tooling are allowed if they are only for your own internal operations and are not offered to third parties.

## Can I publish a public wrapper around Nexori or around the Official Internal Mod Public API?

No. You may not publish a public wrapper, substitute API layer, public API fork, or public "better Nexori API" that functions as an alternative public framework or substitute for the official Nexori integration surface.

## Can I create a minigame or gameplay mod that uses Nexori's official public API?

Yes, if it is an Independent Integration Mod that uses the Official Public API or Official Internal Mod Public API, does not redistribute Nexori, and does not become a competing platform, substitute API, or substitute version of Nexori.

The Official Internal Mod Public API is the official public integration surface inside the mod or game environment. It is not a public web API.

## Can I publish my own public "better Nexori API" or alternate public API fork?

No. Public alternative API forks or public substitute API layers are not allowed.

If you want an API improvement to become public as part of Nexori, submit it to the Official Nexori Project as a pull request.

## Can I publish a public improvement to the Official Internal Mod Public API without a pull request to the official project?

No. Public improvements to that API must go through the Official Nexori Project. The approved public path is a pull request to the official repository.

## Can I publish an improved public version of Nexori instead of sending a pull request?

No. Public alternative versions of Nexori are not allowed. Public improvements must go through the Official Nexori Project.

## Can I submit a pull request so the official project includes my changes?

Yes. Public contributions are welcome through the Official Nexori Project, subject to `CONTRIBUTING.md` and `CLA.md`.

## Can I offer managed Nexori operations to other server owners?

No. Operating, administering, monitoring, automating, or managing Nexori or materially Nexori-based control functionality for third-party owners, tenants, or operators is not allowed as a managed offering.

## Can I charge other server owners for a Nexori-based dashboard, panel, analytics tool, or control layer?

No. A Nexori-based dashboard, panel, analytics tool, admin layer, or control layer offered to third parties is prohibited.

## Can I post small code excerpts from Nexori for review or discussion?

Only in a very narrow way. Limited excerpts for commentary, technical discussion, documentation, or security analysis may be acceptable only if they are no more than reasonably necessary and do not materially enable reconstruction of Nexori or a modified version.

Public forks, patch bundles, and substitute redistributions are still prohibited.

## Do I get trademark rights under the license?

No. The source-available license does not grant trademark or branding rights.

## Can I say "compatible with Nexori"?

Yes, for narrow descriptive use that does not imply endorsement, sponsorship, or official affiliation.
