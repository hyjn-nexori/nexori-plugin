# Contributing to Nexori

Thank you for your interest in improving Nexori.

Nexori accepts public contributions only through the Official Nexori Project identified in `OFFICIAL_SOURCES.md`. Nexori is source-available, not open source, and public forks or public redistributions are not an approved contribution path.

## Public Contribution Path

If you want a change to become part of Nexori publicly, submit that change as a pull request to the Official Nexori Project.

Do not publish public forks, mirrored repositories, public patch bundles, or public modified builds as an alternative contribution path. Private/internal modifications for your own operations are permitted under `LICENSE.md`, but those private/internal modifications do not become publicly distributable.

## Before You Submit a Pull Request

By submitting a pull request to the Official Nexori Project, you confirm that:

1. you have read and will follow `LICENSE.md`, this `CONTRIBUTING.md`, and `CLA.md`;
2. you have reviewed `OFFICIAL_SOURCES.md` and are submitting to an official Nexori channel;
3. you have the legal right to submit the contribution;
4. the contribution is intended for the Official Nexori Project;
5. you understand that accepted contributions may be used, modified, relicensed, commercialized, and incorporated into Nexori and related offerings by Janiel Joel Núñez Quintana; and
6. you accept the Contributor License Agreement in `CLA.md`.

Pull requests that do not satisfy those conditions may be declined.

## Private/Internal Modifications

You may modify Nexori privately for your own internal operations as allowed by `LICENSE.md`. That permission does not allow:

1. public forks;
2. public redistribution of modified source or binaries;
3. rebranding or white-label distribution; or
4. publication of an alternative public version of Nexori or its official public API surfaces; or
5. publication of a public substitute, wrapper framework, or improved public fork of Nexori's Official Internal Mod Public API.

If you want a private/internal improvement to become public as part of Nexori, send it to the Official Nexori Project as a pull request.

## API Evolution

The Official Public API and the Official Internal Mod Public API must evolve publicly through the Official Nexori Project.

The Official Internal Mod Public API is the official public integration surface inside the mod or game environment. It is not a public web API or hosted service API.

Do not publish a separate public API fork, a public "better Nexori API," a public wrapper framework that substitutes for Nexori's API, or a public alternative framework built from Nexori. If you want to improve an official API surface, submit the proposed change through the Official Nexori Project.

## Review and Acceptance

Submitting a contribution does not guarantee review on any particular timeline, acceptance, inclusion in a release, or feedback.

Janiel Joel Núñez Quintana may accept, reject, modify, or request changes to any contribution at his discretion.

## Practical Expectations

Please keep contributions focused, clearly explained, and ready for review.

If your change affects behavior, configuration, security, or official API surfaces, explain the intent and impact clearly in the pull request.

If your change affects the Official Public API or Official Internal Mod Public API, explain why the change belongs in the official project rather than in a private/internal integration layer.
